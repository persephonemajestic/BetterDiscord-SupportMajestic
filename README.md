# SupportMajestic

Плагин для **BetterDiscord**, позволяющий быстро отправлять заранее заготовленные текстовые шаблоны и ответы в чат Discord.

---

## 🚀 Возможности
- Быстрая вставка готовых фраз, шаблонов и ответов поддержки.
- Экономия времени при рутинной модерации и общении.
- Удобное редактирование и настройка списка шаблонов.

---

## 📥 Установка

1. Убедитесь, что у вас установлен [BetterDiscord](https://betterdiscord.app/).
2. Скачайте файл [`SupportMajestic.plugin.js`](https://raw.githubusercontent.com/persephonemajestic/BetterDiscord-SupportMajestic/main/SupportMajestic.plugin.js).
3. Откройте папку с плагинами в Discord:
   - Перейдите в **Настройки пользователя** (`User Settings`).
   - Прокрутите вниз до раздела **BetterDiscord** и выберите **Плагины** (`Plugins`).
   - Нажмите кнопку **Открыть папку плагинов** (`Open Plugins Folder`).
4. Переместите скачанный файл `SupportMajestic.plugin.js` в эту папку.
5. Включите плагин переключателем в списке плагинов Discord.

---

## ⚙️ Использование
После активации плагина настройте нужные текстовые шаблоны в параметрах плагина или вызывайте меню заготовок прямо в поле ввода сообщений.
